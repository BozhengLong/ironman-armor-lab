## R9 · 2026-08-29 · REPULSOR；CI 补齐第三个模型

- **CI 的 manifest 可复现性检查补上 samurai。** 此前只跑 hulkbuster 与 ironman，
  恰好漏掉当初用来做泛化检验的那个。补之前先在本地确认它用默认参数就能逐字节复现。
- **REPULSOR。** 发射口是**推导**出来的，不是标注的 —— 模型里没有任何
  「这里是掌心」的语义。取臂链（shoulder → upper_arm → forearm → hand）
  最远的那一节，方向取「上一节 → 这一节」，发射口落在该节沿此方向的最远角点。
  与姿态无关，手臂垂着还是举着都成立。
  - **不能写死在 `hand` 上**：三个模型的臂链长度都不一样 —— hulkbuster 两侧到 hand，
    samurai 只有左手，**ironman 一个 `hand` 组都没有**，右臂只分离到 upper_arm。
  - 要求末端至少到 forearm，否则该侧不开火。ironman 因此只有左手能发射，
    按钮与 `playRepulsor` 都会明说原因，而不是静默无动作。
- **刻意不引入后处理。** 加 EffectComposer / UnrealBloomPass 会改变渲染路径，
  而 HUD 上的 DRAW CALLS 与 TRIANGLES 是如实读 `renderer.info` 的。
  为一个特效让那两个读数失真不值得。改用叠加混合的 sprite + 点光源 + 射流网格，
  实测三个模型开火时都稳定 120fps，draw call 只多 4 个。

**踩到的三件事，都是「看起来没错但读起来不对」：**

1. **点光源把整具装甲照白。** `intensity=7 / distance=0.9H` 时胸口的红被冲成粉，
   像过曝而不是发光。压到 `0.5 + 1.7 flash / distance=0.4H`，闪光改由 sprite 承担。
   失败态留档 `docs/shots/repulsor-washout-fail.png`。
2. **叠加发光被 ACES 压成灰蓝。** 渲染器开着 `ACESFilmicToneMapping`，
   叠加上去的 0.5 左右会被压回灰色 —— 射流看着像根灰杆子。
   发光材质设 `toneMapped = false` 绕开色调映射才能保住饱和度。
3. **等粗的细长圆柱在正交投影下就是一根杆子。** 改成向远端扩口，
   并用顶点色沿长度衰减（叠加混合下「趋于黑」即「消失」），远端才不是一刀切的断面。

**差点又栽在失败无声上**：`__verifyRepulsor` 第一版写了两条判据 ——
「发射口要在朝外一端」和「离末端组不能太远」。事后发现**两条都恒真**：
发射口由 `center + dir × reach` 构造，而 reach 是包围盒角点投影的最大值，
必然非负且必然不超过半对角线。已换成两条真能失败的：
发射口必须比末端组中心更远离躯干（方向取反即失败）、射流不得指向躯干内部。
配套 `__scrambleRepulsor('flip'|'center')` 作对照组，三个模型上都能让校验变红。

**一处意外的交叉验证**：后坐位移在 `applyTransforms` 走父节点局部空间、
在 `__verifyManifest` 走场景空间再换算到世界空间，是两条独立路径。
峰值时零件实际移动 0.049 身高，而 `maxDeviation` 仍是 2e-6 ——
两条路径在四位小数上一致，等于验证了 `toLocal` 那个矩阵映射是对的。

## R8 · 2026-08-29 · CC-BY 可见署名；移动端媒体查询失效

- **补上 CC-BY 的可见署名。** 站点公开分发六个 GLB，而此前署名只写在清单项的
  `title` 属性里 —— 悬停 tooltip，触屏设备根本触发不到，等于从未随作品送达。
  现在三处：HUD 常驻署名块（桌面右下角 / 移动端底部控制栈末行）、站点根
  `CREDITS.txt`、每个产物目录下的 `ATTRIBUTION.txt`。全部由 `index.json` 生成。
  按 3(a)(1)(B) 声明了「已改动（压缩）」—— 这一条最容易漏。
- **署名数据以 Sketchfab v3 接口为准，并纠正了作者名。** 我们的两份记录互相矛盾
  （`MODELS` 写 `o0ozexo0o`，生成的 `ATTRIBUTION.txt` 写 `dadndan0091`）。
  接口显示前者是 displayName、后者是 username，Sketchfab 页面上显示的是前者。
  三个模型此前记的**全是 username**，已改为按作者指定的显示名署名。
  新增 `--reattribute`：只重写署名文件，不必为改一行字重下 145 MB。
- **构建期守卫**：`build_site.mjs` 在署名字段缺失时直接失败。已用对照组验证
  （抽掉 `authorUrl` / 清空 `license` → 退出码 1 并逐项列出）。
- **移动端媒体查询从来没生效过。** `@media (max-width:820px)` 写在样式表开头，
  而 `#tele` / `#roster` / `#ctl` / `#scrim*` 的基础规则写在它后面 —— 同为 id 选择器、
  特异性相同，媒体查询本身不增加特异性，于是**后写的基础规则一律胜出**。
  只有 `html,body{font-size}` 例外，因为那条基础规则恰好写在前面。
  把媒体查询移到样式表末尾即修复。
  为什么一直没发现：`docs/shots/mobile.png` 是单模型时期拍的 —— 那时没有清单可撞、
  副标题也短，坏掉的布局恰好看起来正常。见 `mobile-mediaquery-dead.png`。
- 修复后暴露出两处真实碰撞（清单/标题压在遥测块上），已让开。
- 新增两个运行时校验，都配了对照组：
  `__verifyCredit()`（署名是否真的可见、三条链接是否与 index.json 一致）、
  `__verifyHud()`（HUD 面板两两不重叠）。10 个视口 + 钻取态全部通过。
- `serve.mjs` 在仓库根找不到文件时退到 `site/`，否则 `CREDITS.txt` 这类
  只在构建时生成的根文件本地链接是死的。
- 更正 README：原文称「本仓库不分发模型文件本身」，站点公开后这句已不成立。
  更正 CI 注释：原文称仓库为 private，与现状相反。

**踩到的**：改 `MODELS` 时锚点少吃了一个 `}`，写出重复右括号 —— 又是同一类锚点错误。
之后每个补丁都先断言锚点唯一，并在改完后立刻做语法检查。

## R4 · 2026-08-28 · 仓库转公开 + Pages 上线

`242341e` `2e73d01`

- **为什么从 private 转 public**：GitHub Pages 在免费计划的私有仓库上不可用；
  更关键的是**仓库可见性保护不了模型** —— 一旦部署到任何公开站点，
  GLB 就是公网可直接下载的。所以「private 仓库 + 公开 Pages」自相矛盾。
  评估过 Cloudflare Pages（免费、可保持仓库私有）与 Cloudflare Access
  （唯一能真正不公开资源的方案），最终选了最简单的公开路径。
- **公开前重写了 git 历史**，移出两份文件：一份是个人对话记录，
  一份含对具体上传者的来源推断（点名的公开指控）。二者仅留本地，已入 `.gitignore`。
  只从 HEAD 移除不够 —— 内容仍在历史里。这是**唯一干净的时机**（当时无 fork 无 star）。
- 提交者邮箱按用户选择保留为真实地址。

**踩到的**：`--force-with-lease` 报 stale info —— `filter-branch` 连本地的
`origin/main` 引用一起重写了，租约期望值失效。需先 `git fetch` 同步真实远端状态。
